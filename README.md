# الملقّن العربي

ملقّن نصوص (تيليبرومتر) عربي مجاني لصنّاع المحتوى: تلصق نصك، تضغط تشغيل، ويمرّ النص قدامك ببطء وأنت تتكلم للكاميرا.

**جرّبه في المتصفح:** https://aldoraibi.github.io/mulaqqin/
**نسخة الماك:** من صفحة [الإصدارات](https://github.com/aldoraibi/mulaqqin/releases/latest)

## المزايا

- تمرير تلقائي بسرعة ثابتة، وتسريع أو إبطاء بالأسهم أثناء القراءة
- تحكم بحجم الخط، وخط قراءة ذهبي يحدد السطر اللي تقرأه
- وضع المرآة لزجاج الملقّن
- الشاشة ما تنطفي أثناء التشغيل
- تحرير النص مباشرة، واللصق يدخل نصاً نظيفاً بدون تنسيقات
- نصك يُحفظ على جهازك فقط، ولا يُرسل لأي مكان
- في نسخة الماك: «فوق كل النوافذ» (⌘⇧T) عشان تحط النافذة تحت الكاميرا مباشرة

## الاختصارات

| الاختصار | الوظيفة |
|---|---|
| مسافة | تشغيل / إيقاف |
| ↑ ↓ | أسرع / أبطأ |
| ⌘ + / ⌘ − | تكبير / تصغير الخط (الماك) |
| ⌘ ⇧ T | فوق كل النوافذ (الماك) |
| ⌃ ⌘ F | ملء الشاشة (الماك) |

## تثبيت نسخة الماك

1. نزّل ملف `Mulaqqin-mac.zip` من صفحة الإصدارات وافكّ ضغطه.
2. انقل «الملقّن العربي» إلى مجلد التطبيقات وافتحه.
3. التطبيق غير موثّق من أبل، فبيطلع لك تحذير أول مرة. روح إلى **إعدادات النظام ← الخصوصية والأمان**، وانزل تحت واضغط **«فتح على أي حال»**.

يشتغل على ماك ١٢ وأحدث، بمعالجات أبل وإنتل.
